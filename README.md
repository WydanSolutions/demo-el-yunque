# Demostración · Página de gestión para El Yunque

Demostración de una página de gestión para barracas y ferreterías, desarrollada por
**Wydan Solutions**: stock con lotes y vencimientos, ventas conectadas al stock, facturación,
presupuestos, acopios, entregas con hoja de ruta, compras y proveedores, cuentas corrientes,
comisiones del funcionario y finanzas.

- **Todos los datos son inventados.** No hay información real de ninguna persona ni empresa.
- Funciona por completo en el navegador: no hay servidor ni base de datos.
- Contraseña de la demostración: `1234` (sirve para los dos usuarios: Dueños y Funcionario).

Cada persona que abre la página trabaja con su propia copia de los datos de ejemplo,
guardada solo en su navegador.
